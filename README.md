# outdir

Small macros for including files generated in `OUT_DIR` during the build step.

This crate is useful when `build.rs` creates assets or generated source files and you want to include them as compile-time constants without reading them at runtime.

## Features

- Include generated source files with `outdir!`
- Include generated bytes with `outdir_bytes!`
- Include generated UTF-8 text with `outdir_str!`
- Works well for build-time generated content such as templates, data files, and static assets

## Installation

Add this crate to your project:

```toml
[dependencies]
outdir = "0.1"
```

## Usage

The examples below are illustrative and are intentionally skipped by Rustdoc because they rely on a `build.rs` step and the `OUT_DIR` environment variable.

Create a file in `build.rs` and place it under `OUT_DIR`:

```rust,ignore
use std::{fs::File, io::Write};

fn main() {
    let out_dir = std::env::var("OUT_DIR").unwrap();
    let path = std::path::Path::new(&out_dir).join("hello.txt");
    let mut file = File::create(path).unwrap();
    file.write_all(b"TEST MESSAGE").unwrap();
}
```

Then read it in your application code:

```rust,ignore
const MSG: &str = outdir::outdir_str!("/hello.txt");
assert_eq!("TEST MESSAGE", MSG);

const BYTES: &[u8] = outdir::outdir_bytes!("/hello.txt");
assert_eq!(b"TEST MESSAGE", BYTES);

const SOURCE: &str = outdir::outdir!("/hello.txt");
```

## Notes

- The path passed to the macro is relative to `OUT_DIR`.
- It is intended for files created during the build process.
- The macro expects a string literal such as `"/hello.txt"`.
